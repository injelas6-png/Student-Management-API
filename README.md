Student Management API

This project is a simple Student Management API that I built to understand how backend development works with Node.js, Express.js, and MySQL. The API connects to a MySQL database and allows student information to be added and retrieved through API requests. I used Postman to test the API and verify that the data was successfully stored and fetched from the database. This project helped me gain practical experience in creating APIs, connecting a backend application to a database, and working with request and response methods.

Key Highlights
Built a REST API using Node.js and Express.js
Connected the application to a MySQL database
Implemented POST API to add student details
Implemented GET API to retrieve student information
Tested API requests and responses using Postman
Verified student records directly from the MySQL database
Practiced backend development and database connectivity
